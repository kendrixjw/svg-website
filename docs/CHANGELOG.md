### Decisions made

**Architecture — Option A (owner-approved).** Static HTML on GitHub Pages plus a
small Node build step. Rejected: accepting duplication (violates spec §9), and
migrating to Next.js/Astro (violates spec §22, changes deployment). Generated
HTML is committed and self-sufficient; the site still works if Node disappears.

**Venture naming.** "StridePM" in the spec refers to the venture shipped as
**OpsConduit**. Owner confirmed the public name stays OpsConduit — no rename, no
new slug, no redirect, existing OG image stays valid. StridePM appears nowhere
on the site.

**Venture statuses** (owner-supplied; three corrected what the live site shows):

| Venture | Status | Live site said |
|---|---|---|
| Devotion After Victory | Beta | In Development ❌ |
| OpsConduit | Live | In Development ❌ |
| Lumira | In Development | Live ❌ |
| Lottery Pattern Engine | Live | ✔ |
| Vocasa · Accountability Workout App | In Development | ✔ |
| Family Reunion | In Development | new |

Added **Beta** as a fourth status with its own steel-blue pill. All four states
(Live / Beta / In Development / Coming Soon) are now visually distinct; previously
every venture used `status-dev` regardless of its label.

**Venture URLs** — all owner-supplied, all verified HTTP 200 with matching page
titles before use:

| Venture | URL |
|---|---|
| Devotion After Victory | `https://devotionaftervictory.com` |
| OpsConduit | `https://opsconduit.vercel.app` |
| Lottery Pattern Engine | `https://lottery-pattern-engine.vercel.app` |
| Vocasa | `https://vocasa-seven.vercel.app` |

| Lumira | `https://lumira-kohl.vercel.app` |
| Family Reunion | *(none — in development)* |

**Lumira's link demoted, not removed.** Now In Development, so its CTA reads
"Preview the build" rather than "Visit". The URL still resolves.

**Contact form: no fake backend.** No form service is configured, so the form
validates client-side and composes a complete message into the visitor's mail
client. Setting an `action` on the `<form>` makes the JS handler stand down —
switching to Formspree/Netlify/Basin is a one-line change.

**Analytics: instrumented, not installed.** Every CTA carries
`data-event` / `data-venture-name` / `data-venture-url` / `data-cta-location`.
The dispatcher forwards to `gtag` or Vercel's `va` if present and **no-ops
silently otherwise** — nothing faked, nothing broken. Events wired:
`venture_click`, `venture_view`, `service_click`, `consultation_click`, `contact_submit`.

**Contrast fix.** Added `--gold-ink` (`#8a6420`) for gold text on parchment;
the previous `#c89b3c` measured roughly 3:1 and failed WCAG AA for body text.
`--gold` is now reserved for non-text use (borders, rules, fills).

**Build validates its own data.** Throws on an unrecognized status value or a
non-HTTPS venture URL, so a bad edit fails the build instead of shipping.

### Corrections to earlier reporting in this session

1. **The vector logo does not exist.** The Phase 1 audit claimed the legacy
   `sovereign-valor-group-website/` folder held vectors of the eagle-and-crown
   emblem that could replace the 252 KB PNG. It does not — those three `.svg`
   files are abandoned early concepts (a shield, a wordmark, a star). The PNG
   stays; optimization is still open.
2. **Mobile was never visually verified.** The screenshot tool renders at a fixed
   width regardless of resize. The mobile nav is verified by source only
   (toggle markup, `aria-expanded` wiring, Escape handler, focus trap, ≤768px
   breakpoint). Needs a real-device check.
3. **`serve.mjs` had a crash-then-hang bug.** The 404 handler wrote its status
   line before reading `404.html`, so a missing file left the response half-open;
   a first fix attempt swallowed the error without ending the request, turning a
   crash into a hang. Fixed by resolving the body before writing headers.
   Dev-only tooling — never shipped, no visitor impact.
4. **Venture naming question went unanswered.** Family Reunion vs. Spades & Bones
   was asked but not answered; defaulted to venture **"Family Reunion"** with
   **"Spades & Bones"** as its product subtitle, slug `family-reunion`, monogram
   `FAM`. One line in the registry to change.
